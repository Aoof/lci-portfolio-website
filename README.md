# LaSalle Portfolio Website

A responsive single-page portfolio built with Bootstrap 5 and jQuery for a web development course at Collège LaSalle (April 2025). My current portfolio is at [aoof.ca](https://aoof.ca); this repository is the course version.

**Live demo:** https://aoof.github.io/lci-portfolio-website/

## Features
- Hero carousel, About, Projects and Contact sections
- Project cards generated from a JavaScript array, each with a details modal
- Dark mode toggle
- Contact form with Bootstrap validation and a simulated send (no back end)
- Bootstrap Icons

## Project structure
```
index.html      page layout
css/style.css   custom styles and dark mode
js/script.js    project cards, modal, dark mode, form validation
images/         project and section images
```

## Run it locally
No build step. Clone the repository and open `index.html` in a browser.
